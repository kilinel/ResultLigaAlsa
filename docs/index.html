Ajuda e dados

Como mencionar jogadores e cargos?

No Discord, ative Configurações → Avançado → Modo desenvolvedor. Clique com o botão direito no nome da pessoa e escolha Copiar ID do usuário. Para cargos, vá às configurações do servidor → Cargos e copie o ID do cargo; se necessário peça ao administrador. Não use o ID da mensagem. Cadastre o número aqui para gerar a menção correta. Se aparecer cargo desconhecido, confira o ID na lista de cadastros: a menção deve ser <@&ID> e o cargo deve existir no mesmo servidor onde você colou. Se o nome aparece mas a notificação não chega, verifique se o cargo permite menções ou se você tem permissão para mencioná-lo.

Onde ficam meus dados?

Os dados ficam neste navegador, sem login ou servidor de armazenamento. Limpar os dados do navegador pode apagar os cadastros. Exporte um JSON para backup ou para usar em outro dispositivo. Partidas também ficam no backup web. O JSON pode conter nomes e IDs: guarde-o com cuidado.

Como funcionam os templates e stats?

Ranked termina com três vitórias, em até cinco partidas. Escolha stats totais ou por partida; o segundo modo soma pelo jogador. Use {stats1}, {stats2}, {stats_por_partida} ou {partida1_stats1} até {partida5_stats2}. Ajustes manuais na prévia ficam preservados até clicar Gerar novamente.

Como copiar?

Clique Copiar mensagem e cole no Discord. Se o navegador bloquear a cópia, selecione o texto da prévia e use Ctrl+C. Emojis personalizados devem existir no servidor. Mensagens longas podem exigir envio em partes.

Backup JSON

Importe um backup web ou o preferencias.json do desktop. Cadastros com o mesmo nome serão atualizados; os demais serão mantidos.
