# Privacidade — ALSA Match Results Web

A versão web prepara mensagens para o Discord e funciona sem login, token de bot ou webhook. Ela não envia resultados ao Discord: o botão Copiar coloca a mensagem na área de transferência quando solicitado.

## Armazenamento local

Jogadores, cargos, IDs, templates, partidas, stats e edições da prévia ficam no armazenamento local do navegador, neste dispositivo. O aplicativo não envia esses dados ao autor ou a um serviço de sincronização. Navegadores e dispositivos diferentes possuem dados separados.

Para remover todos os dados locais, use a opção de limpar os dados deste site nas configurações do navegador. Isso apaga o armazenamento local; arquivos JSON exportados permanecem onde você os salvou e precisam ser excluídos separadamente.

## Importação e exportação

O arquivo JSON exportado contém seus cadastros e dados preenchidos. A importação lê o arquivo localmente. Guarde backups com cuidado e não os publique se contiverem informações pessoais. A importação das preferências desktop mantém os cadastros existentes e atualiza nomes iguais.

## Hospedagem

O aplicativo não inclui publicidade, analytics ou telemetria. O GitHub Pages hospeda os arquivos e processa os acessos conforme a [política de privacidade do GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Ao publicar mensagens no Discord, aplicam-se as políticas desse serviço.
